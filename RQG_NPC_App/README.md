# RuneQuest: Roleplaying in Glorantha — Standalone NPC Character Sheet & Generator (`RQG_NPC_App`)

Dedicated local-first web application containing the **NPC Character Sheet & Generator** for **RuneQuest: Roleplaying in Glorantha (RQG)**.

See **[Instructions.md](./Instructions.md)** for full usage and GitHub Pages deployment instructions.

## Quick Start
- **Offline (No Setup)**: Double-click [`runequest_npc_app.html`](./runequest_npc_app.html) (or `dist/index.html`) in your browser.
- **GitHub Pages**: Upload this folder to a GitHub repository and enable **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**. Visiting the repository URL automatically opens `runequest_npc_app.html`.
- **Development**:
  ```bash
  npm install
  npm run dev
  npm run build
  ```
