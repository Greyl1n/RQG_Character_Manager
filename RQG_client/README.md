# RuneQuest: Roleplaying in Glorantha — Character Companion & Manager (`RQG_client`)

Complete local-first web application for **RuneQuest: Roleplaying in Glorantha (RQG)** featuring an interactive Player Character Sheet, 6-step Character Creation Wizard with House-Rule support (editable Skill Category Bonuses & free Profession Skill % allocation), Skill Experience Level-Up roller, Roster Manager, Printable Sheet, and integrated NPC Character Sheet & Generator.

See **[Instructions.md](./Instructions.md)** for full usage and GitHub Pages deployment instructions.

## Quick Start
- **Offline (No Setup)**: Double-click [`runequest_app.html`](./runequest_app.html) (or `dist/index.html`) in your browser.
- **GitHub Pages**: Upload this folder to a GitHub repository and enable **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**. Visiting the repository URL automatically opens `runequest_app.html`.
- **Development**:
  ```bash
  npm install
  npm run dev
  npm run build
  ```
